# BADSHAH-AI v2 — Phase 21 VS Code Coding Agent

Adds:
- Workspace/repo code scanner
- Safe code patch proposal generator
- Explain code file command
- Test runner helper
- VS Code open helper
- Coding dashboard tab

## Commands

```text
code scan
code explain main.py
code patch add dark mode to dashboard
code test
open vscode
```

```bat
installer\INSTALL_BADSHAH_AI.bat
```
