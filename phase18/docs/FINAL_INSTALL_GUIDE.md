# Final Install Guide

1. Install Python 3.10+
2. Install Ollama
3. Run:
   ```bat
   installer\INSTALL_BADSHAH_AI.bat
   ```
4. Pull model:
   ```bat
   installer\PULL_OLLAMA_MODEL.bat
   ```
5. Start:
   ```bat
   installer\START_BADSHAH_AI.bat
   ```

Optional:
- Browser automation: `installer\INSTALL_BROWSER_ENGINE.bat`
- Dashboard: `installer\START_DASHBOARD.bat`
- Voice: `installer\START_VOICE_MODE.bat`
