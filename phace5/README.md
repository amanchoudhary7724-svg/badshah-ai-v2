# BADSHAH-AI v2 Phase 5 — Self Modification Safe Mode

Adds:
- Health check
- Installer scripts
- Task history
- Workspace export
- Safe self-modification proposal system
- Code patch files generated in `workspace/patches/`
- Review-first architecture

## Setup Windows

```bat
scripts\setup_windows.bat
scripts\run_cli.bat
```

## Commands

```text
health check
create website portfolio
self modify add dark mode to dashboard
self improve browser agent
show patches
export workspace
tasks
```

## Important

Self modification is SAFE:
- It does not overwrite core project files automatically.
- It writes proposed files/patch notes under `workspace/patches/`.
- You review then manually apply.
