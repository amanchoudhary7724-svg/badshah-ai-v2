# Multi-Agent Planner

## Commands

```text
plan create website portfolio and remember project name
run plan create website portfolio and export workspace
agents
planner status
```

## Agents
- ChatAgent
- MemoryAgent
- WorkspaceAgent
- FileAgent
- BrowserAgent
- SystemAgent
- ReleaseAgent

The planner breaks a user request into steps and routes each step to the safest available agent.
