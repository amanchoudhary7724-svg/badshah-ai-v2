# Gmail + Calendar Agents

## Email Drafts

```text
draft email Aman project update kal bhej dena
followup email Aman quotation pending
meeting invite Aman product demo Friday 4pm
```

## Calendar Drafts

```text
calendar draft Team Meeting tomorrow 5pm
show calendar drafts
```

## Safety

All actions save local drafts only:
- `workspace/drafts/`
- `workspace/calendar/`
