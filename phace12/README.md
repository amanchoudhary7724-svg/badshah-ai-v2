# BADSHAH-AI v2 — v1.2 Installer Edition

Simple local AI assistant launcher package.

## 1. Install

Double-click:

```text
scripts/setup_windows.bat
```

## 2. Run

CLI:

```text
scripts/run_cli.bat
```

Dashboard:

```text
scripts/run_dashboard.bat
```

API:

```text
scripts/run_api.bat
```

## 3. Commands

```text
help
version
health check
validate env
create website portfolio
release package
```
